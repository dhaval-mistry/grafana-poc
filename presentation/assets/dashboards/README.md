# Dashboard screenshot drop zone

Place Grafana dashboard screenshots here using these exact base names:

- executive-overview.png or executive-overview.jpg or executive-overview.jpeg
- customer-experience.png or customer-experience.jpg or customer-experience.jpeg
- journey-investigation.png or journey-investigation.jpg or journey-investigation.jpeg
- api-health.png or api-health.jpg or api-health.jpeg

The HTML decks automatically try PNG, JPG, and JPEG in that order. If no image is found, a clean placeholder is shown.
